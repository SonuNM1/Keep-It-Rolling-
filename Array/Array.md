# Array DSA Roadmap (Pattern Wise)

> Master the patterns, not the individual questions. Most array interview problems are variations of these patterns.

---

# 1. Traversal Pattern ⭐ (Easy)

### Concept
Traverse the array once and compute the required result.

### Questions

- Find Maximum Element
- Find Minimum Element
- Find Largest & Smallest Element
- Find Second Largest Element
- Find Second Smallest Element
- Sum of Array
- Average of Array
- Count Even Elements
- Count Odd Elements
- Count Positive Numbers
- Count Negative Numbers
- Count Zeros
- Frequency of an Element
- Frequency of Every Element
- Find Missing Number (Sum Formula)
- Check Array is Sorted or Not

**Time Complexity:** `O(n)`

---

# 2. Two Pointer Pattern ⭐⭐

### Concept
Use two indices moving towards each other.

### Questions

- Reverse Array
- Reverse First Half & Second Half
- Reverse Each Element
- Palindrome Array
- Two Sum (Sorted Array)
- Move Zeros to End
- Move Zeros to Beginning
- Segregate Even & Odd
- Sort 0s and 1s
- Remove Duplicates from Sorted Array
- Container With Most Water
- Trapping Rain Water (Optimized)

**Time Complexity:** `O(n)`

---

# 3. Rotation & Shifting Pattern ⭐⭐

### Concept
Shift or rotate elements.

### Questions

- Left Rotate by One
- Right Rotate by One
- Left Rotate by K
- Right Rotate by K
- Insert Element at Position
- Delete Element from Position
- Shift Left
- Shift Right
- Circular Rotation
- Cyclic Rotation

**Time Complexity:** `O(n)`

---

# 4. Prefix Sum Pattern ⭐⭐⭐

### Concept
Store cumulative sums.

### Questions

- Running Sum of Array
- Prefix Sum Array
- Range Sum Query
- Pivot Index
- Equilibrium Index
- Subarray Sum Equals K
- Count Subarrays with Given Sum
- Product of Array Except Self (Prefix-Suffix)

**Time Complexity:** `O(n)`

---

# 5. HashMap / HashSet Pattern ⭐⭐⭐

### Concept
Remember previously visited elements.

### Questions

- Two Sum
- Contains Duplicate
- First Unique Element
- Majority Element
- Longest Consecutive Sequence
- Intersection of Two Arrays
- Frequency Count using HashMap
- Find Duplicate Element

**Time Complexity:** `O(n)`

---

# 6. Sliding Window Pattern ⭐⭐⭐⭐

### Concept
Maintain a moving window instead of checking every subarray.

### Questions

- Maximum Sum of Size K
- Minimum Sum of Size K
- Maximum Average Subarray
- Longest Subarray with Sum K
- Maximum Consecutive Ones
- Longest Sequence of Ones
- Fruits Into Basket
- Longest Substring Without Repeating Characters
- Minimum Window Substring

**Time Complexity:** `O(n)`

---

# 7. Prefix Min / Prefix Max Pattern ⭐⭐⭐⭐

### Concept
Maintain the best value seen so far.

### Questions

- Best Time to Buy and Sell Stock
- Maximum Difference
- Prefix Maximum Array
- Prefix Minimum Array
- Rain Water Trapping (Left Max & Right Max)

**Time Complexity:** `O(n)`

---

# 8. Kadane's Algorithm Pattern ⭐⭐⭐⭐

### Concept
Maintain the best answer ending at the current index.

### Questions

- Maximum Subarray Sum
- Maximum Circular Subarray Sum
- Maximum Product Subarray
- Largest Sum Contiguous Subarray

**Time Complexity:** `O(n)`

---

# Pattern Recognition Cheat Sheet

| If the Question Says... | Pattern |
|--------------------------|---------|
| Largest, Smallest, Count, Sum | Traversal |
| Reverse, Palindrome, Swap Ends | Two Pointers |
| Rotate, Shift, Insert, Delete | Rotation & Shifting |
| Running Sum, Range Sum | Prefix Sum |
| Pair Sum, Duplicate, Frequency | HashMap |
| Maximum/Minimum Subarray of Size K | Sliding Window |
| Buy & Sell Stock, Maximum Difference | Prefix Min / Prefix Max |
| Maximum Sum Subarray | Kadane's Algorithm |
| Sorted Array Search | Binary Search |
| Missing Number, Duplicate Number | Cyclic Sort |
| Matrix Problems | Matrix Pattern |
| Overlapping Ranges | Interval Pattern |
| Jump, Platform, Gas Station | Greedy |
| Merge, Kth Largest, Sort | Sorting Pattern |

---

# Recommended Learning Order

1. Traversal
2. Two Pointers
3. Rotation & Shifting
4. Prefix Sum
5. HashMap
6. Sliding Window
7. Prefix Min / Prefix Max
8. Kadane's Algorithm
9. Binary Search
10. Cyclic Sort
11. Matrix
12. Interval
13. Greedy
14. Sorting Based Problems

> **Master one pattern completely before moving to the next.** Once you recognize the pattern, solving the problem becomes much easier than memorizing individual solutions.
